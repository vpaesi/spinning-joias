# Spinning Joias

Catálogo digital da Spinning Joias, feito com React, TypeScript e Vite. Permite pesquisar e filtrar produtos e consultar fotos, descrições, preços e variações. A compra é assistida pelos canais da loja; o site não oferece carrinho nem checkout.

## Requisitos

- Node.js 26.x
- npm

## Instalar e executar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm test
npm run lint
npm run build
```

O catálogo é mantido em `public/produtos.json`; as imagens locais ficam em `public/images/produtos/`. A especificação geral do projeto e os registros de planejamento ficam fora deste repositório, em `../SPEC.md` e `../spinning-joias-documentacao/`.
